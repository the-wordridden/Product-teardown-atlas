**One primitive.** "A block object represents a piece of content within Notion" <Evidence id="block.api.primitive" />. The API lists more than thirty types, a `has_children` flag for nesting, and `child_page` as a type of its own: a page is itself a block. A document and a database aren't different products; they're different arrangements of the same material.

## How two people edit at once

Each block is "stored as a separate database record", and concurrent edits merge through a CRDT based on the Replicated Growable Array <Evidence id="crdt.architecture.2026" />. Before July 2025 it was last write wins, under which "one person's edits would be completely lost." Notion names the cost too: you "may need to potentially fetch many blocks in order to find a particular text slice" <Evidence id="crdt.limitation.2026" />.

Figma, elsewhere in this Atlas, rejected CRDTs and built a central server authority. Two collaborative editors, opposite answers.

## The cost of blocks

A database record per paragraph is expensive. Notion sharded Postgres across 480 logical shards, and a practitioner reported companies leaving because it was too slow <Evidence id="block.sharding.2021" />. The primitive that makes it flexible makes it hard to serve.

## The surfaces

- **Editor and databases**, both built from blocks.
- **Notion Sites**, which publishes any page to the open web. It's how template artefacts reach people with no account <Evidence id="gallery.artefact.observed" />.
- **The template gallery**: 30,000 templates in 348 categories, all public <Evidence id="gallery.scale.2026" />.
- **Notion AI**, gated to Business and Enterprise <Evidence id="ai.plan-gate.2026" />.
- **The API**, which arrived in 2021 after users asked for it at launch.

The desktop app also detects meetings, which support described as "microphone monitoring combined with network port analysis" <Evidence id="desktop.meeting-detection.2025" />. A counter-voice noted that checking whether a mic is active is not listening to it. Both are true.
